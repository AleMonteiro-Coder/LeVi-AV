# LeVi | A.V. — Software & Technology

*Technology, Guided by Vision.*

## Sobre o projeto

A LeVi | A.V. nasceu como uma proposta de marca voltada à tecnologia e ao desenvolvimento de soluções digitais.

Esta página foi criada para apresentar um pouco dessa ideia, mostrando os serviços, a identidade visual e a forma como a tecnologia pode ser usada para transformar ideias em projetos reais.
